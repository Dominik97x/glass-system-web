# D4.2 — katalog Bitrix: kompletne zadaszenia i ogrody

## Decyzja biznesowa

Standardowy produkt w CRM odpowiada temu, co realnie zamawiamy u dostawcy.

- ZP = kompletne zadaszenie tarasu z poliwęglanem.
- ZS = kompletne zadaszenie tarasu ze szkłem.
- OP = kompletny ogród zimowy z dachem poliwęglanowym.
- OS = kompletny ogród zimowy z dachem szklanym.
- Ogród zimowy NIE jest składany w Bitrixie jako zadaszenie + ściany + trójkąty.
- Elementy standardowo należące do OP/OS nie są dodawane drugi raz jako osobne pozycje.

## Źródło cen

Produkty ZP/ZS/OP/OS oraz montaż korzystają z arkusza `03_Cennik_uslug_nowy` w aktualnym modelu MoonGlass:

- produkt: `Cena sprzedaży netto/kalk.`
- montaż: `Cena montażu netto`

Nie zastosowano zapowiadanej zmiany cennika dostawcy od 09.08.2026. Aktualizacja cen nastąpi dopiero po otrzymaniu nowego oficjalnego cennika.

## Przykład 350 × 506 cm

- Ogród zimowy Modern PRO — szkło — cena katalogowa MoonGlass: 29 766 zł netto.
- Cena dostawcy tego kompletnego OS: 20 528 zł netto / 25 250 zł brutto.
- Montaż ogrodu: 4 680 zł netto — osobna pozycja.

Standardowy OS zawiera elementy przewidziane przez dostawcę dla kompletnego zestawu. Nie dodajemy do niego osobno standardowych ścian, szkła ściennego ani trójkątów.

## Dodatki operacyjne

Katalog nadal zawiera osobno m.in.:

- roletę ZIP boczną — jedna pozycja; przy dwóch bokach ustawiamy ilość 2,
- roletę ZIP front,
- markizę,
- fundament / profil poziomujący,
- LED punktowe,
- LED RGB CCT,
- szczotki,
- uchwyty,
- zabieraki.

Prawdziwe dopłaty pozostają osobnymi produktami:

- poliwęglan mleczny / szary / przyciemniany,
- szkło dachowe przyciemniane / mleczne,
- szkło ścienne przyciemniane.

LED CCT bez RGB nie jest obecnie publikowane do katalogu operacyjnego zgodnie z informacją o braku dostępności do października. Nie zmieniamy na tej podstawie innych cen.

## Elementy techniczne D4.1

Trójkąty, dodatkowe systemy ścian, krokwie, profile i słupy pozostają w katalogu jako pozycje CRM-only dla konstrukcji niestandardowych.

Nie służą do składania standardowego OP/OS. Opisy produktów zostały w D4.2 doprecyzowane, aby handlowiec nie doliczał elementu już zawartego w kompletnym ogrodzie.

## Oczekiwany katalog D4.2

Na aktualnym cenniku generator powinien utworzyć około 1267 produktów:

- 640 pozycji rdzenia CRM: ZP/ZS/OP/OS, montaż, dopłaty, LED RGB CCT,
- 560 współdzielonych dodatków operacyjnych,
- 67 technicznych dodatków CRM-only.

Szkło ZS/OS dla wymiarów 550/600 pozostaje niepublikowane, ponieważ bieżący cennik nie zawiera pełnych zatwierdzonych danych dla tych wariantów.

## Kolejność wdrożenia

1. `npm run bitrix:products:full:source`
2. `npm run lint`
3. `npm run build`
4. `npm run bitrix:products:full:plan`
5. Sprawdzić liczbę `extraManagedSkus` — będą tam stare testowe pozycje z poprzedniego modelu.
6. Dopiero po kontroli planu uruchomić pełny import.

Nie uruchamiać `apply` przed przejrzeniem nowego planu.
