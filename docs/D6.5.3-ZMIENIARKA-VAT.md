# D6.5.3 — zmieniarka VAT w Dealu Bitrix24

## Cel

Mechanizm przelicza wszystkie pozycje produktowe wybranego Deala na jedną stawkę VAT.
Zachowuje ceny netto i wylicza nowe ceny brutto, a następnie aktualizuje harmonogram 30/50/20.

## Obsługiwane stawki

Presety: `0%`, `5%`, `8%`, `23%`.

Można również podać inną stawkę od `0` do `100` z dokładnością do dwóch miejsc po przecinku.
Stawka niestandardowa wymaga przy zapisie flagi `--allow-custom-rate` i potwierdzenia księgowego.

`ZW` i `NP` nie są procentami i nie są obsługiwane przez tę wersję mechanizmu.

## Nowe pola Deala

- `VAT dokumentu / produktów [%]`
- `Status przeliczenia VAT`
- `Data ostatniego przeliczenia VAT`
- `Podsumowanie ostatniego przeliczenia VAT`

Istniejące pole `Stawka VAT` pozostaje dla zgodności z wcześniejszą integracją. Przy 8% i 23% jest ustawiane na odpowiednią wartość. Dla 0%, 5% i stawek niestandardowych otrzymuje wartość `Indywidualna`.

## Bezpieczeństwo

- `preview` nie zapisuje żadnych zmian,
- `set` wymaga jawnego potwierdzenia,
- przed zmianą zapisywany jest backup Deala i pozycji,
- metoda Bitrix24 zastępuje cały zestaw pozycji, dlatego skrypt odtwarza wszystkie pozycje w jednym wywołaniu,
- w przypadku nieudanego przeliczenia skrypt próbuje automatycznie przywrócić poprzednie pozycje,
- skrypt odmawia działania, gdy pozycje mają VAT poza ceną (`TAX_INCLUDED != Y`) albo rabaty zapisane bezpośrednio w wierszach produktów.

## Przykłady

Podgląd zmiany na 23%:

```powershell
npm run bitrix:vat:preview -- --deal-id=3 --rate=23
```

Zapis zmiany na 23%:

```powershell
npm run bitrix:vat:set -- --deal-id=3 --rate=23 --confirm=MOONGLASS-VAT-CHANGE-DEAL
```

Stawka 5%:

```powershell
npm run bitrix:vat:set -- --deal-id=3 --rate=5 --confirm=MOONGLASS-VAT-CHANGE-DEAL
```

Stawka niestandardowa 7,5%:

```powershell
npm run bitrix:vat:preview -- --deal-id=3 --rate=7.5
npm run bitrix:vat:set -- --deal-id=3 --rate=7.5 --allow-custom-rate --confirm=MOONGLASS-VAT-CHANGE-DEAL
```

Można też wpisać procent w polu Deala i użyć:

```powershell
npm run bitrix:vat:preview -- --deal-id=3 --from-deal
npm run bitrix:vat:set -- --deal-id=3 --from-deal --confirm=MOONGLASS-VAT-CHANGE-DEAL
```
